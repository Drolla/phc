# Agents

Empty for now. Once this project defines a specialized subagent role (e.g.
a Claude Code subagent for a project-specific job), add one Markdown file
per agent here describing its role and when it applies, and list it in
`../index.json` under `agents` — so every supported coding-assistant tool
can discover and follow its role description, not just the tool that can
execute it natively.
